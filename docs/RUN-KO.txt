Sonora 0.1.0 — Windows 실행 안내

1. 설치 없이 사용: Sonora-0.1.0-x64-portable.exe를 실행합니다.
   설치해서 사용: Sonora-0.1.0-x64-nsis.exe를 실행합니다.
   두 가지 중 하나만 사용하면 됩니다. 첫 실행은 압축 해제로 잠시 걸릴 수 있습니다.

2. 파일 선택 또는 드래그로 영상·오디오를 추가하거나 YouTube 주소를 추가합니다.
   이용 권한이 있는 콘텐츠만 처리하세요. 로그인·DRM·접근 제한을 우회하지 않습니다.

3. MP3 비트레이트와 저장 폴더를 확인한 후 '전체 시작'을 누릅니다.
   기본값은 192 kbps입니다. 높은 비트레이트가 원본 음질을 개선하지는 않습니다.
   설정 메뉴에서 이름 규칙과 중복 파일 정책을 바꿀 수 있습니다.

4. 완료 목록에서 '폴더에서 보기'로 MP3를 확인합니다.
   원본은 수정하지 않으며 기존 파일을 덮어쓰지 않습니다.
   오류·취소 작업은 '재시도' 후 '전체 시작'으로 다시 실행할 수 있습니다.

환경: Windows 10 22H2 / Windows 11 x64. 로컬 NTFS 저장 폴더를 권장합니다.
변환 도구가 포함되어 있어 Python·FFmpeg를 따로 설치할 필요가 없습니다.
로컬 파일은 PC 안에서 처리합니다. YouTube 작업에는 인터넷 연결이 필요합니다.
최대 입력 2 GiB·24시간, 다운로드/변환 단계당 최대 30분입니다.

이번 빌드는 코드 서명이 없는 평가판입니다. Windows가 게시자를 확인할 수 없다는
안내를 표시할 수 있습니다. 전달된 체크섬과 출처를 확인한 파일만 실행하세요.
설치 프로그램은 자동 실행하지 않았습니다. GitHub Release도 게시하지 않았습니다.
